# Stacklink Round One Pitch Example

A 5-slide pitch for Stacklink, originally built for the Round One Ventures workshop. Bundled here so cinemorph operates self-contained without needing an external deck path.

Run:

```
/cinemorph new --from-example stacklink-roundone-pitch
```

Customize via `--theme`, `--tokens`, `--prompt`, or by editing the cloned `stages.ts` / `data.ts` after generation.
